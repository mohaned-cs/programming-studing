## Calculator (`calculator.py`)
This is a simple calculator project I made using Python.

**What it does:**
- Asks the user to enter two numbers.
- Lets the user choose an operation (+, -, *, /).
- Prints the result.
- Prevents error if you try to divide by zero.

**How to run it:**
python calculator.py
